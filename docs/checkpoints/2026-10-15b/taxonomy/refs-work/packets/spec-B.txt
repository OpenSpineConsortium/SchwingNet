=== [unit mggj4hxkexp.7397] heading level 2
3. The taxonomy

=== [unit mggj4hxkexp.7413] paragraph
No published taxonomy answers the question this spec asks. The academic taxonomies of agents read for it (2024 to 2026) classify by architecture, control structure, interaction type, autonomy, environment, memory and domain; none has an axis for where the compute runs and who pays for it (Inferred from the dozen read, not a systematic review; research note 13). Industry categories moved in 2025 and 2026 from assistants to agents: Gartner's 2025 report was a Magic Quadrant for AI Code Assistants (Reported, from a news digest), and a single secondary page, possibly machine-written, reports a 2026 Magic Quadrant for Enterprise AI Coding Agents (Reported). Thoughtworks' Technology Radar Vol 34 (April 2026) named "agent-native project memory and task tracking" a new category, with Beads as its example, put a small team of coding agents in Assess and coding agent swarms in Caution (Reported, from a dataset of the radar). The CNCF landscape has an AI Agent category with eleven subcategories, none for coding agents or for coordinating them (Verified, landscape.yml).
    links in this unit: "landscape.yml" -> https://github.com/cncf/landscape/blob/master/landscape.yml

=== [unit mggj4hxkexp.11164] paragraph
Three axes carry this study. Axis 10 is where the Actions story lives and the one no taxonomy has. Axis 5 is where Symphony's claim sits: a claim made by creating a branch, a lease-like release and optimistic merging. Axis 11 is where Beethoven's claim sits: a tool, never a model, decides. Axes 1, 3 and 7 locate the neighbors.

=== [unit mggj4hxkexp.11483] paragraph
The classical frames fit closely. Malone and Crowston define coordination as "managing dependencies among activities" and name four families of dependency, one of which, producer and consumer, splits into prerequisite, transfer and usability (Reported, from mirrors of the paper; research note 13). Each of the six kinds has a counterpart in agent work: claiming an issue is a shared resource, a blocker is a prerequisite, a pull request is a transfer, a required check is a usability standard, the landing order of overlapping work is simultaneity, and an epic is task and subtask (Inferred; research note 13).
