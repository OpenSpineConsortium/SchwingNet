9. GitHub Actions nativeness and free public minutes

=== [unit mggj4hxkexp.22158] heading level 3
9.1 What "Actions-native" means here

=== [unit mggj4hxkexp.22195] paragraph
Symphony's coordinator is not a service that talks to GitHub; it is a set of GitHub Actions jobs that run when GitHub says something happened. The board, the idle-claim release, the overlap notices, the dealing of work to workers, the protocol check and the cleanup are deterministic code on the workflow's own GITHUB_TOKEN, with no Claude call and no server. GitHub's own events trigger them, GitHub's concurrency queue serializes them, GitHub's refs make the claim atomic, and GitHub's rulesets and required checks enforce the result. Claude runs only where judgment is needed, as a job on the same runners. Verified, research note 01.

=== [unit mggj4hxkexp.22833] heading level 3
9.2 What is free

=== [unit mggj4hxkexp.22852] list item
GitHub's docs: "Use of the standard GitHub-hosted runners is free and unlimited on public repositories" (supported-github-runners.md, Verified 2026-10-15). Self-hosted runners are free on every plan.
    links in this unit: "supported-github-runners.md" -> https://github.com/github/docs/blob/main/data/reusables/actions/supported-github-runners.md

=== [unit mggj4hxkexp.23053] list item
A public repository gets twice the machine a private one does: Linux and Windows standard runners with 4 vCPUs, 16 GB and a 14 GB SSD, against 2 vCPUs and 8 GB in a private repository. Verified.

=== [unit mggj4hxkexp.23249] list item
The governance a coordination protocol needs is free there too: rulesets, required checks and code owners on GitHub Free, environments with required reviewers and wait timers (which on Free, Pro and Team exist only for public repositories), CodeQL code scanning, secret scanning with push protection, and Dependabot. Symphony's gate and its owner-approved release environment rely on this. Verified; GitHub's own pages disagree on whether dependency review is free on a public repository, and most say it is.

=== [unit mggj4hxkexp.23759] list item
GitHub announced a $0.002-a-minute charge on self-hosted runners on 2025-12-16 and withdrew it from the docs the next day; secondary sources say it is postponed, not cancelled (Verified from the github/docs history; Reported for the postponement).

=== [unit mggj4hxkexp.25436] heading level 3
9.4 What still costs money

=== [unit mggj4hxkexp.25465] list item
Inference is never free. Symphony's Actions workers run on one person's Claude plan through CLAUDE_CODE_OAUTH_TOKEN (Pro $20 a month, or $17 billed annually; Max $100 or $200), and they share that plan's five-hour window and weekly limit with the person's own use. The Max and Team monthly API credits do not cover runs of the Claude Code GitHub Action. Verified, research note 10.

=== [unit mggj4hxkexp.25848] list item
A private repository gets 2,000 included minutes a month on Free, 3,000 on Pro and Team, 50,000 on Enterprise Cloud, then $0.006 a minute on Linux (since 2026-01-01), each job rounded up to a whole minute, and usage stops at the quota without a payment method. Rulesets that enforce the gate need Pro or Team there. Verified.

=== [unit mggj4hxkexp.26175] list item
An illustration (Inferred; the workload is an assumption): ten one-hour Claude runs a day is 18,000 runner minutes a month. On a public repository that costs nothing in minutes. On a private repository on Team it is 15,000 minutes over the quota, about $90 a month, before the board's own runs, each of which bills at least a minute.

=== [unit mggj4hxkexp.26510] list item
AI review layers (Copilot code review, GitHub's AI Scan, Claude Code Review) bill credits even on public repositories; Symphony's rules keep them out of the gate. Verified, research note 12.

=== [unit mggj4hxkexp.26701] heading level 3
9.5 The terms that govern it

=== [unit mggj4hxkexp.26732] list item
GitHub's Actions terms (effective 2026-04-27) forbid offering Actions "or any elements of the Actions product or service, for commercial purposes", disproportionate burden, and, on GitHub-hosted runners, "any other activity unrelated to the production, testing, deployment, or publication of the software project associated with the repository" (Verified, github/site-policy). Agents writing and testing the repository's own code sit inside that line (Inferred). A benchmark that runs other projects' tasks, and a paid App whose runtime rides each customer's free minutes, need a reading (Open, question R5).
    links in this unit: "github/site-policy" -> https://github.com/github/site-policy/blob/main/Policies/github-terms/github-terms-for-additional-products-and-features.md

=== [unit mggj4hxkexp.27342] list item
Anthropic documents the subscription token for claude-code-action and says runs then "use your Claude subscription instead of API billing", but advises an API key for a secret shared across repositories, since the token is tied to one person's plan; its legal page says plan limits "assume ordinary, individual usage" (Verified, GitHub Actions, legal and compliance). Whether several Actions workers on one plan are ordinary, individual usage is not stated (Open, question R6).
    links in this unit: "GitHub Actions" -> https://code.claude.com/docs/en/github-actions; "legal and compliance" -> https://code.claude.com/docs/en/legal-and-compliance

=== [unit mggj4hxkexp.27821] list item
Claude Code's docs say bare mode will become the default for claude -p and that bare mode does not read the OAuth token; whether claude-code-action will keep the subscription path working is not stated (Open, question R6).

=== [unit mggj4hxkexp.28044] heading level 3
9.6 Why it matters

=== [unit mggj4hxkexp.28065] list item
A coordination step costs nothing. Claiming, releasing, ordering overlaps and rendering the board are runner minutes on GITHUB_TOKEN, free on a public repository, with no model call. Neighbors that coordinate with a model, or through a hosted service, pay for every step.

=== [unit mggj4hxkexp.28338] list item
A Claude run costs plan usage, not dollars. Until the plan's window is reached, one more worker run has no metered price. Of the neighbors examined that run agents in Actions, gh-aw, openai/codex-action and Copilot's agents meter inference by the token or the credit; aeon runs one agent on the subscription token but coordinates no claims (sections 5 and 8).

=== [unit mggj4hxkexp.28543] list item
There is nothing to host. No server, database or daemon of the project's own: the forge is the lock, the CI is the scheduler, and the repository is the state. That removes the setup and the bill that keep a coordinator out of a small project, and it survives the churn of agent frameworks (section 5).

=== [unit mggj4hxkexp.28846] list item
The offer is GitHub's alone, so far. No other major hosted CI found still offers new public projects unlimited free minutes (Azure Pipelines keeps them only for existing public projects, until those turn private in 2027): section 7.3 lists who withdrew, and CircleCI caps open source at 400,000 credits a month (Reported, from its pricing page by search). That is also a dependency: one vendor's pricing decides the economics (section 10).

=== [unit mggj4hxkexp.29006] list item
It does not reach Beethoven as built. Beethoven's repositories are private and its science needs the cluster and GPUs, which Actions never gives free. Actions fits Beethoven as the control and verification plane, with the cluster as the compute plane, as its CI already does: the gate runs on GitHub's runners and a grid lane posts commit statuses back. A public Beethoven gate library would run free (Inferred).
