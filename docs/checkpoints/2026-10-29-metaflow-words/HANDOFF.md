## 3. The experiment port's review, not yet applied

An adversarial review of commit 458e6ea (four reviewers, read against main at fade5aa) found these; the verification of each was cut short by the checkpoint, so each is the reviewer's claim, read once by the thread and found plausible on the code:

1. flows/experiment.py, flow_command: every request gets `--weights <the ResNet-18 ImageNet file>`, so a request whose block names another architecture (resnet34, say, which the issue form offers and `experiments_panel.py check --request` accepts) is refused by the trainer at its first epoch, after the job was queued. The old plain job did the same. Decided fix: refuse such a request in words before any frame is read, in the driver (a `block: architecture=` other than resnet18 fails the job with "architecture=<name>: no ImageNet file for it on the grid, so the request waits for one") and again in the flow's start, so every requested combination starts from ImageNet as version 1 does, as tools/block_sweep.py's weights_for refuses a row without a file; the PREREG's section 2 weights bullet is then made to say so and section 5 gains the line, before the refreeze below.
2. flows/experiment.py, start: the request file is hashed into the key but never compared with the words the run trains on (--recipe, --epochs, --seed, --hours, --blocks), so a hand launch whose words differ from the file trains the words and records the file. Decided fix: start reads the file with the driver's line grammar and raises a fault unless the values equal the parameters; end hashes the file again and fails where it differs from start's request_sha256.
3. flows/experiment.py, end: a request whose configuration equals version 1's (the form's defaults) finds V1Flow's finished folder (tools/flow.py names a run by code, catalog and configuration alone), and end overwrites its METAFLOW.json. Decided fix: write METAFLOW.json only where the folder holds none or it names ExperimentFlow and this issue; else write METAFLOW-experiment-<issue>.json beside it; a test where an experiment reuses a folder V1Flow finished.
4. docs/research/experiments/PREREG.md, section 2 and the opening: it cites grid/experiment-driver.sbatch at commit 28f0387 as design text, where that driver ran a plain job. Decided fix: refreeze before the merge (the PREREG is not on main), citing the driver and flows/experiment.py as committed with the file, with section 7 recording the second freeze and the first freeze's hash; DEVIATIONS.md stays "No entry yet".
5. grid/experiment-driver.sbatch: the request check (`experiments_panel.py check --request`, tens of seconds in the container) runs before the job writes grid/logs/HOLD, so a gate word sent in that window fast-forwards the checkout between the check and the run. 6. grid/experiment-driver.sbatch and flows/experiment.py: on a resume whose train_evaluate step Metaflow cloned, nothing prints the run_dir line, so the report says "run directory: none was made" beside verdict 0. Decided fix: end prints the `{"run_id": ..., "run_dir": ...}` line too.
