## Plan

Make every catalog build an immutable, read-only version named by its content, with an append-only version log that carries each version's parent and its accounting (what was added and removed, counts per source and part), and open it with SQLite's read-only, immutable URI so no reader can write or lock it. Fix the dataset tree to one systematic shape: one lower-case source id per folder, alphabetical, shards under it by date and content hash, frames fanned out by hash prefix, so a new dataset is one new folder and one registry file. Record the comparison with Google's, Meta's and the medical consortia's practice under docs/research/ and fold what it teaches into the design note.
