## Plan

The five findings of the data-input audit, each with a test that fails before the fix. A frame that is not 8-bit grey, a 16-bit PNG or a 16-bit or 32-bit image read through Pillow, is windowed to 8 bits in the bank by the same window the DICOM path uses, and the ingest refuses a 16-bit grey frame by name as a second fence, so no frame reaches the trainer to be clipped white; an 8-bit PNG is still copied byte for byte. The bank writes BANK.json, a stamp of the recipe, the raw listing and the bank code, and a rerun whose stamp matches decodes nothing. The ingest answers "already there" for a bank whose shard is already there under another date or commit, cuts no dated twin, and skips reading the bank at all when the shard's own report holds the same bank stamp and inputs. The catalog drops a build that differs from the latest version only in the code commit, so a merge to main makes no new version from unchanged shards. Dot folders under shards/ are never read as shards, and staging folders a killed ingest left are cleared after the stage's time limit. The audit itself lands as a research note, with the findings this leaves raised as an issue.
