## Plan

Make the synthesis of the artifacts keep itself current. A state file records the tree each artifact's inventory record was read from and each dataset record's hash, so one command names what is new, changed or gone; every inventory and verdict quote is checked against today's texts, so a stale verdict is found by script; a concept ledger built from the dataset records' counts and the figures the record has settled checks every artifact, research note and dataset record against them, reporting only what a change brings. A workflow on every push runs these with no Claude and keeps one issue current; where reads wait, it runs them on the repository's Claude token, as the owner chose on 2026-10-23, at most 10 runs a day, and opens one pull request with what they read.
