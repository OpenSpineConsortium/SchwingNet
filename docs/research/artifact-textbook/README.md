# The Artifact Textbook

The thread "Artifact Textbook", 2026-10-22, the owner's ask: one reference book that synthesises everything in the owner's collected claude.ai artifacts, to be read when planning experiments, written into this private repository under docs/textbook/ and never copied outward, with the Symphony and Beethoven material kept in a separable part. Where it stands:

- Phase 1, the inventory, is landed: artifacts/_synthesis/ holds one record per artifact (inventory.json, inventory.md), the clustering into fourteen topics with superseded versions collapsed (clusters.md), the quantities two artifacts give differently with the quotes matched to their sources by script (contradictions.md, 247 number collisions and the disagreements of three clusters), and the proposed table of contents (table-of-contents.md, eight parts, thirty-two chapters, every artifact placed, nine questions for the owner). Chapters wait for the owner's reading of that plan.
- Phase 2, the research: for each cluster, what the artifacts assert without a source, what is stale, what the public literature says, every claim graded Measured, Reported, Inferred or Unverified and cited as a link naming the artifact; the eleven clusters not yet swept for contradictions; where the cloud environment cannot reach a source, it is listed and never filled from memory. Not started.
- Phase 3, the book under docs/textbook/, one chapter per file, each ending with what we know, what we do not know, what would change our mind and a provenance table. Not started.
- Phase 4, the experiment planning layer: a pre-registration stub per candidate experiment, ranked by information gain over cost, with what needs the owner's word before any job, the quick wins that need no grid time and the negative results so nothing is retried. Not started.

How the inventory was made, so that the next phase can be made the same way: each artifact's page was reduced to plain text by script (the embedded page of a Design-type artifact included), e-mail addresses and phone numbers replaced before any reader saw it; readers, three artifacts at a time, wrote one record each from the text and the artifact's own files; three readers clustered the records by different lenses (the question answered, the stage of the work, the reader and the decision) and a fourth settled one clustering; two readers went over the numbers table for collisions and one per cluster for disagreements; and a script checked every candidate's quotes against the extracted text and the page's own files. Every count in the records was checked by script: every artifact id placed exactly once, no address of any kind in any file, every file ASCII.

No grid job, training run or paid usage was submitted for this work, and none is planned by it: the book reads records and plans experiments; running one waits for the owner's word and the number, as docs/research/README.md requires.
