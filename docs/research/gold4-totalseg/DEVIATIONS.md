One lattice, measured per axis. Part 3 calls two maps one grid when "every corner voxel [lies] within 0.01 mm of its twin". The code that was sent, tools/gold4_totalseg_grid.py's same_grid with AFFINE_SLACK_MM, holds each axis of a corner's offset within 0.01 mm, so a corner may lie up to 0.01 mm times the square root of 3, about 0.017 mm, from its twin in a straight line. Part 3's reason holds for the bound the code applies: each axis of the offset is an affine function of a voxel's place, whose largest size over the grid lies at a corner, so no voxel's offset passes 0.01 mm on any axis. Both bounds are under a fiftieth of a millimetre, and the rule's purpose, Dice read only where no resampling bridges the two maps, is kept by either. No code, word, record or bar changed, and the run goes on as sent. Not known: how many units, if any, have a corner between 0.01 and 0.017 mm from its twin in a straight line while every axis stays within 0.01 mm; the records keep only how the lattice was shared (one grid, reoriented or another lattice), not the offsets.
