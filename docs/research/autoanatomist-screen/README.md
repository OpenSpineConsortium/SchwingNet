# The auto-anatomist screen: where it stands

Source: the thread "Restart the auto-anatomist probe", 30 October 2026. Confidential with the rest of this repository.

The screen asks whether annealing the auto-anatomist's privileged input helps the fully latent network name and outline real vertebrae on gold tier 3 CTs, under PREREG.md beside this file, frozen before any send. It runs as the launched flow autoanatomist (flows/autoanatomist.py, flows/README.md): each trial is one run of the flow on a card, and the join is one run on a CPU node that decides each arm against the null and writes the CLAIM 2024 and REFORMS report (tools/report.py with tools/autoanatomist_report.py).

- The plans: grid/screens/gold3_latent_smoke.json, two short trials in series on one card, an anneal and the null, then the join, which tries the code path end to end and whose numbers are read as nothing; and grid/screens/gold3_latent_screen.json, three anneal schedules against the null that never anneals, two seeds each, 50 epochs on 96 training CTs, read on 24 validation CTs by the mean surface distance. tools/autoanatomist_plan.py writes them from the gold 3 store and checks them against the frozen split and the test lists, and PREREG.md's Covers line holds each by its bytes.
- The grid words: `autoanatomist gold3_latent_smoke`, then `autoanatomist gold3_latent_screen` (grid/gate.sh, grid/autoanatomist.sbatch). The owner's counts: the smoke is the one short GPU smoke of his count of 2026-10-30 03:20 UTC, and the screen is the two jobs of his word of 08:56 UTC, a GPU array of eight trials and a CPU join afterany it. A plan is sent once; it is sent again only once a fix has moved the checkout after a send that failed, or on his word in AUTOANATOMIST_RERUNS.
- The network: bordercall's auto-anatomist, its copy under grid/autoanatomist/ (tools/bordercall_vendor.py), a block the plans' words choose. The trials run on the grid's Python 3.11, in a venv over the train-gpu environment with the versions schwingnet.autoanatomist_screen.PINS names (jax 0.10.2, flax 0.12.8, optax 0.2.8, orbax-checkpoint 0.12.8).
- How to read a result: the join's finals.png and curves.png, each with a line under it on how to read it, and SUMMARY.md; RECORD.json names every file the decision read by its sha256. An arm beats the null only where every one of its seeds ends below every one of the null's.

Where it stands on 30 October 2026: nothing has been sent. The latent-prior evaluation's test reserve (bordercall PR 45) joins the test lists first, so both studies keep one person split, and the plans and the PREREG are written again over it before the first send.
