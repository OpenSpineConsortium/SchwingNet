# History

This folder is for the longer record of the project: what was decided and why, what a piece of work found and settled, what a session's checkpoint brought over. Research, a programme being measured or a note of what a piece of work found, accumulates under docs/research/ (.claude/rules/research.md) and stays there; a pull request that settles a finding for good may move it here. Later layers of the template will write here under one folder per topic, docs/history/<topic>/; today nothing writes here, and a person may add a page by pull request when a record is worth keeping and is neither a memory fact (docs/memory/) nor a checkpoint (.claude/session.md).

What never lands here: raw event logs (.events.json or any other dump of a session's events), tool output, transcripts, or anything a person would not read. The checks refuse an .events.json anywhere in the repository.
