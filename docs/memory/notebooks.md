A notebook is a private repository pointing at a few drive files by id, never moving them, with research, drafts and references beside them.

tools/notebook.py checks a proposal (notebooks.json beside catalog.json on a private repository's branch drive-catalog) against the catalog, gives each notebook's counts, writes a notebook repository's starting files and reads a BibTeX or RIS export into references.json; .claude/skills/notebook is the procedure. Edits to the files go through the lens-review skill as tracked changes in a copy. Elsevier's text and token may be used privately, never made public (the university's library to the owner, 2026-10-19); references go into Word through tools/docx_cite.py as tracked Word CITATION fields with the document's source list, or Zotero fields naming the library item, which names its source; no citation connector exists for Claude (2026-10-19), and an Actions worker reaches no WSU OneDrive before admin consent, so background work is a scheduled Claude task with the Microsoft 365 connector on the owner's word. docs/research/notebooks.md.
