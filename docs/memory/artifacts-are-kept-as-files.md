Every claude.ai artifact of every account of the owner's is kept as files in artifacts/ of the repository its work belongs to, so any account can edit and republish it.

The owner asked on 2026-10-22 that all artifacts be pushed into the repositories, editable by anyone, and consolidated across all his accounts continuously. An artifact on claude.ai belongs to one account and only its Share menu, which a session cannot change, lets others see it; a file in a repository is read and changed by every account through pull requests.

- Where: artifacts/ at the repository's root (outside docs/, whose ASCII rule the pages' typography would break). Symphony and Beethoven artifacts go to OpenSpineConsortium/symphony-template; spine, fluoroscopy, SchwingNet and spine-program ones to OpenSpineConsortium/SchwingNet, the only place SchwingNet's patent material may go.
- Shape: one folder per artifact, named in kebab-case after its title; a page as index.html with every other published file beside it at its published path; a Claude Docs document as index.md, exported as Markdown. artifacts/README.md has one row per artifact: title, folder, link, what it is.
- How: Artifact tool action list (scope all) for the account's artifacts; action read with path index.html, plus a scope files listing and a paths read for the rest; for a Docs document, Claude Docs read of the link, then export of its tab as markdown. A Design-type artifact's own files are under project/; its index.html is only the type's shell.
- Ongoing: each new artifact a session makes is added the same way in the pull request of the work it came from, and a session on another account repeats the export for that account's artifacts. The repository copy is the one to edit; republish from it with the Artifact tool.
