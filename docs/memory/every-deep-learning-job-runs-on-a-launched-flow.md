- flows/registry.txt is the one list of the flows: kind, class, the launcher's last-line word, the grid job script that starts it, and its PREREG.md, or - for bank and catalog, which train and run no network. `python3 flows/stage_registry.py check`, in scripts/check.sh, fails on a line that does not hold or a PREREG that is not the one frozen.
- A PREREG is frozen as the Lab Recipe says: `sha256sum PREREG.md > PREREG.md.sha256`, both committed, never edited; a departure goes in DEVIATIONS.md, and a correction of a departure is a new dated entry below the last, never an edit of an earlier one. Every PREREG the registry names is under docs/research/. `python3 flows/stage_registry.py frozen` (scripts/check.sh) holds it by git: a PREREG.md or .sha256 under docs/research/ or docs/history/ that the base holds may not change, a DEVIATIONS.md beside a frozen PREREG only grows, and a frozen folder may move whole to docs/history/. In CI the base is the commit the pull request was merged onto, never a newer main; elsewhere where HEAD left origin/main, skipped with a line where git cannot tell. scripts/check.sh runs main's own copy of the check against the checkout, so loosening the check in the same change does not pass; an edit of check.sh's frozen_check or of ci.yml still can, which its diff shows. The launcher refuses a missing or moved PREREG with exit 90 before it imports Metaflow; a `Covers:` line names the parts it covers (the sweep's plans), each as `<part>=<sha256>` where its bytes are held too, and a run of any other part, or of a part whose bytes changed, is refused with exit 90 too, after Metaflow is imported (the flow's own file names the part) but before the datastore is touched; a refusal by the flow's own start or end (`StageFault`) fails the run, so the launcher exits 1, not 90. The gate's `sweep` word refuses an uncovered or edited plan in bash before it queues anything. The block smoke test's is docs/research/block-smoke/PREREG.md, covering synthetic, real and two_source by their bytes; the six trials wait for a PREREG of their own.
