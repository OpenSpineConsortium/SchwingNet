Every deep learning job on the grid runs on a flow flows/launch.py starts, under a PREREG frozen before the run, with the CLAIM 2024 and REFORMS report enforced and a progress page in the browser; a plain Slurm job is not enough (the owner's rule of 2026-10-29 02:39 UTC).

- The owner's words, on finding run 2 of the DRR study and the Flux realism stages sent as plain Slurm jobs: "dude wtf was the point of me making that pipeline if you arent using it! that should be a fucking requirement for all deep learning jobs i run on the grid".
- flows/registry.txt is the one list of the flows: kind, class, the launcher's last-line word, the grid job script that starts it, and its PREREG.md, or - for bank and catalog, which train and run no network. `python3 flows/stage_registry.py check`, in scripts/check.sh, fails on a line that does not hold or a PREREG that is not the one frozen.
- A PREREG is frozen as the Lab Recipe says: `sha256sum PREREG.md > PREREG.md.sha256`, both committed, never edited; a departure goes in DEVIATIONS.md. The launcher refuses a missing or moved PREREG with exit 90 before it imports Metaflow; a `Covers:` line names the parts it covers (the sweep's plans), and a run of any other part is refused the same way. The block smoke test's is docs/research/block-smoke/PREREG.md, covering synthetic, real and two_source; the six trials wait for a PREREG of their own.
- Each flow's steps use flows/stage.py: hold_to_prereg in start, Beat (and run_watched, passed) around each step, claim_report in end (tools/report.py write then check; a report not current makes the verdict 1), finish for the verdict on the page.
- The page: <datastore root>/progress/<Flow>/<run>/index.html, on the grid under /rs/rs_grp_oschome/go2432/metaflow/progress/, reached through Open OnDemand's Files app (untried yet); the status word prints the newest four runs' PROGRESS.txt under `## flow <kind> <run>, progress (...)`, and tools/progress_page.py draws the page from that answer off the grid.
- The version 1 run keeps it too: grid/v1-driver.sbatch starts `flows/launch.py v1` (flows/v1.py), held to docs/research/v1-demo/PREREG.md, frozen as an estimate with no accuracy bar on the owner's choice of 2026-10-29 03:23 UTC, with DEVIATIONS.md beside it for where the run as built departs from the plan.
