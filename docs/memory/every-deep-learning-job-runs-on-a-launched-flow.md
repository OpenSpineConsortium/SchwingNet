- flows/registry.txt is the one list of the flows: kind, class, the launcher's last-line word, the grid job script that starts it, and its PREREG.md, or - for bank and catalog, which train and run no network. `python3 flows/stage_registry.py check`, in scripts/check.sh, fails on a line that does not hold or a PREREG that is not the one frozen.
- A PREREG is frozen as the Lab Recipe says: `sha256sum PREREG.md > PREREG.md.sha256`, both committed, never edited; a departure goes in DEVIATIONS.md. `python3 flows/stage_registry.py frozen` (scripts/check.sh) holds it by git: a PREREG.md or .sha256 that origin/main holds may not change, and a DEVIATIONS.md beside a frozen PREREG only grows. The launcher refuses a missing or moved PREREG with exit 90 before it imports Metaflow; a `Covers:` line names the parts it covers (the sweep's plans), each as `<part>=<sha256>` where its bytes are held too, and a run of any other part, or of a part whose bytes changed, is refused the same way. The block smoke test's is docs/research/block-smoke/PREREG.md, covering synthetic, real and two_source by their bytes; the six trials wait for a PREREG of their own.
- Each flow's steps use flows/stage.py: hold_to_prereg in start, Beat (and run_watched, passed) around each step, claim_report in end (tools/report.py check first, since a check right after a write always passes: a report the run left current is well, one it left stale is written anew and makes the verdict 1, and a folder with none has it written at the end), finish for the verdict on the page.
- The page: <datastore root>/progress/<Flow>/<run>/index.html, on the grid under /rs/rs_grp_oschome/go2432/metaflow/progress/, reached through Open OnDemand's Files app (untried yet); the status word prints the newest four runs' PROGRESS.txt under `## flow <kind> <run>, progress (...)`, and tools/progress_page.py draws the page from that answer off the grid.
