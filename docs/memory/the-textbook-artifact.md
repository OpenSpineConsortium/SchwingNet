The Artifact Textbook is also one private claude.ai artifact, published and republished to the same link by .github/workflows/textbook-artifact.yml after each merge to main that changes the book; it lands in the artifact gallery of the account whose token is the secret CLAUDE_CODE_OAUTH_TOKEN, private until that account shares it, and no session publishes it from anywhere else.

The owner decided on 2026-10-24 (a decision card at 18:15 UTC, issue #236) that the book goes to claude.ai rather than claude.ai coming to the book: a live claude.ai artifact answers content-security-policy frame-ancestors 'self' and two extension ids and serves its content from a per-artifact frame origin, so no other site, the members-only Pages site included, can embed one (docs/research/textbook-as-an-artifact.md). At 18:42 UTC the owner chose where the publish runs: a GitHub Action on every push to main that changes the book, not the owner's machine, not a slash command, not a routine. On 2026-10-24 a cloud session's guard had refused the Artifact publish of the built edition as data exfiltration, even with the owner's card, so a session never publishes the book itself; the workflow is the one place.

How it works. tools/textbook_artifact.py turns the site tools/textbook_site.py wrote into the artifact's files: the front page as the Artifact tool's page proper (no document skeleton, its title and style first), every other page whole, the figure records left out and "The record" pointing at GitHub at the built commit (the data a figure is drawn from stays), the viewer's theme toggle given token overrides, an edition line on the front page naming the commit and its own date (never the clock, so one commit builds the same bytes twice), and on every page the Ask Claude box, one shared ask.js that answers from the page's text through the artifact runtime's sample capability on the viewer's own account, with a button on every figure. tools/textbook_publish.py is the workflow's helper: a fingerprint of the book's inputs at a commit (git ls-tree over the same paths the push filter names), whether a run may publish, the plan of what changed since the record (the files hashed, batches of at most 240 files and 60 MiB, deletions as null entries, the page always the publish's file_path), the mechanical prompt (paths and hashes, nothing of the book's text; the only text the session sees is what the tool's own read of the front page returns), the session's arguments (the Artifact and Read tools alone, the user's settings, 40 turns) and the record. The record is state.json on the branch textbook-artifact, written by the job record alone, with GITHUB_TOKEN, as fast-forward commits on the branch's head, never replacing a branch that holds anything else: the link, the commit and date the edition was built from, the fingerprint and every published path's sha256. The link is there and in each run's job summary.

When it runs and when it does not. A push to main touching docs/textbook/, artifacts/, tools/textbook_site.py, tools/textbook_artifact.py, tools/living_docs.py or .github/CODEOWNERS; every half hour (13 and 43 past), since a merge GitHub's auto-merge makes starts no workflow; and Run workflow. A run stops, saying why in its summary, when the variable TEXTBOOK_ARTIFACT is off, in crowd mode, without the token, when the fingerprint it would build from is the one already published (Run workflow builds anyway), or once the day's publishes, counted from the branch's commits, reach TEXTBOOK_PUBLISHES_PER_DAY (12 unless the variable says otherwise, 50 at most). A new run cancels one still publishing; a publish cut short leaves the record as it was, or, where the session reported the link, records the link with nothing published, so the next run publishes the whole edition to the same artifact and never makes a second one. If the session has no Artifact tool it prints ARTIFACT_TOOL_MISSING and the run fails loudly; whether claude-code-action's session carries the tool is proven by the first run, which is dispatched by hand after the merge. A first publish cancelled before its session answered can leave an artifact the record does not know; the owner deletes it from the gallery.

The edition built from the site of 2026-10-24 is 442 files and 103.6 MB, two publish batches, 41 exported artifact pages among them, under the tool's limits of 255 files and 64 MB a publish and 511 files and 256 MB a version. Nothing of the book is public before the provisional is filed (docs/memory/the-textbook-website.md); the artifact is shared, if at all, from its Share menu by the account that holds it.
