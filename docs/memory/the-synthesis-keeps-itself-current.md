The synthesis keeps itself current: .github/workflows/synthesis.yml looks at every change with no Claude, and runs the Claude reads a change needs, at most 10 runs a day, each opening a pull request that waits for the owner's tap.

- The stamp, artifacts/_synthesis/work/out/state.json, holds each artifact folder's git tree as its record read it and each dataset record's hash, with what was already known when it was stamped. `SYNTH_SYMPHONY=<a checkout of symphony-template> python3 -I -B artifacts/_synthesis/work/tools/synth.py status` names what is new, changed or gone, the quotes today's texts no longer hold and the concept checks the stamp has not seen, with no Claude.
- The workflow looks on every push to main that changes artifacts/ outside artifacts/_synthesis/, docs/research/ or data/sources/, daily at 06:41 UTC for symphony-template's artifacts, and on Run workflow, and keeps one open issue labelled synthesis saying what waits.
- Its reads run on the repository secret CLAUDE_CODE_OAUTH_TOKEN, a `claude setup-token` token on that account's plan limits with no API billing, by the owner's choice of 2026-10-23 that they start on their own: at most 10 runs a day (the variable SYNTHESIS_READS_PER_DAY), and none while the variable SYNTHESIS_READS is off, in crowd mode, without the SymphonyBoard App's SDLC_APP_ID and SDLC_APP_PRIVATE_KEY, or for six hours after three failed runs.
- Each run that reads opens or updates one pull request from a branch synthesis/<run>, one commit on main; the App opens it, so each push waits for the owner's tap on owner-ok, and it merges by itself once green (automerge.yml).
- What a run writes goes through artifacts/_synthesis/work/tools/redact.py (a login, the owner's first name, a form's link), is saved in the records' own layout (synth.save) and is the same on every hash seed: `python3 -I` draws a new seed in every process, so a set whose order reaches a result is sorted, and tests/test_synthesis.py checks four seeds.
- A dataset record whose name gives the concept checks the wrong names for its set is set right in artifacts/_synthesis/work/aliases.json.
- artifacts/_synthesis/work/RESUME.md, section Keeping it current, is the whole account.
