# Artifacts

Every artifact in the claude.ai artifacts gallery the owner's accounts made for this repository's work, kept here as files so any account can read, edit and republish them. Each folder holds one artifact: index.html for a page (with any image beside it), index.md for a Claude Docs document, exported as Markdown with its embedded widgets dropped. The link is the published artifact on the account that made it; this copy is the one to edit, by pull request, and to republish from with the Artifact tool on any account; when you republish a folder from another account, add the new link to that folder's row. The grid keeps the same files in the owner's private ~/claude-artifacts/SchwingNet, where a worker on any of his accounts reads them: symphony-template's .github/workflows/artifacts-grid.yml brings them there every six hours and whenever a session starts it after a merge here.

To add the artifacts of another account, open a session on OpenSpineConsortium/symphony-template from that account, with this repository beside it, and run `/export-artifacts <a name for the account>` (symphony-template's .claude/skills/export-artifacts), which sorts each artifact to this repository or to symphony-template and opens one pull request in each; if the command is not found, the skill is not on symphony-template's main yet. By hand it is: list them (Artifact tool, action list), read each page (action read, path index.html, and each other file a scope files listing shows), export each Docs document as Markdown (Claude Docs export), add one folder each here and one row below, in one pull request. Patent material (SchwingNet's methods) goes only to OpenSpineConsortium/SchwingNet, never to a public repository, and the skill never shares any of them.
