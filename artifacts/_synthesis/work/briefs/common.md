How to read a source. Each artifact you are given names its id (repository/folder), its title, its date as the inventory read it (it may be null or only a month), text (the artifact's page reduced to plain text, with e-mail addresses and phone numbers already removed) and folder (the artifact's own files: index.html or index.md, and any scripts, data and images). To find a quote, search the text file with the Grep tool for a distinctive fragment of 20 to 40 characters of it, as plain text and ignoring case; where it is not there, search the folder the same way, since the text cuts each line of a page's script data at 600 characters. Then read the passage around it with the Read tool, enough to know what quantity, scope, denominator, version and date each statement is about and whether either page says it revises, repeats or follows the other, and read more when the scope is unclear. A long file is read in parts. Keep what you have read in mind rather than reading it again.

The verdict scales. For a cluster candidate (any stratum but "Number collisions"): confirmed (both sources say what the candidate says and they really disagree; for kind stale, a later source or the artifact's own later section shows the statement no longer holds; for unsourced-shared-claim, the claim is in each source and no source for it is given; for duplicate-text, one text or figure carried by both, so one claim and not two confirmations), superseded-by-later (one source is later, by its date or because it plainly follows the other, and revises the earlier), refuted (they agree once read in context, a different scope, subset, unit, interval or date that the pages themselves state, or a statement or quote is not in its source), cannot-tell (the texts do not settle it). For a number collision: confirmed-contradiction (the same quantity over the same scope with different values), updated-later (the later source, by its date or because it plainly follows the other, gives a new figure for the same quantity), same-number-restated (the values agree once read), scope-or-unit-differs (the same name over a different subset, denominator, unit, interval, version or date, as the pages state), different-quantities (not the same thing), cannot-tell.
