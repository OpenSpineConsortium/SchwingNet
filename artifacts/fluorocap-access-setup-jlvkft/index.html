FluoroCap Access Setup

What to obtain, where to get it, and where to put it so the harvesters can use it without any secret ever being printed or committed. Ranked by how much of the resolution problem each one fixes.

00Start here, because the biggest fix is already free

The figure PMC serves is the rendition the publisher deposited; the publisher's own site keeps the larger file, and for five of the corpus's largest publishers the figure URL is deterministic from the DOI and the PMC file name. Measured this afternoon on real corpus figures, no login involved:

16×Cureus · 750×1017 → 3000×4067
9–20×MDPI · 713×259 → 3211×1165
12×Elsevier CDN · 788×926 → 2760×3242
6×Frontiers · 770×609 → 1925×1522
4×Springer, BMC, Nature · 721×1132 → 1443×2266

That refetch is running now over every PMC figure in the corpus. Eighteen of the twenty-one test figures were replaced; the three that were not are on SAGE, which blocks non-browser clients and is what the credentials below are for. Nothing in this page is needed for the run in progress.

01How the hand-over works

One file on the WSL machine, readable only by you, outside every repository. Values go in with an editor, never on a command line, so they never enter a shell history or this conversation.

python tools/fluorocap_creds.py init     # creates ~/.fluorocap/credentials.env (mode 600) from the template
nano ~/.fluorocap/credentials.env        # fill in the values
python tools/fluorocap_creds.py check    # prints WHICH keys are set and probes each service. Never a value.
Environment file~/.fluorocap/credentials.env holds every key; a blank line skips that route and the harvester falls back to credential-free behaviour.
Cookie jars~/.fluorocap/cookies/<site>.txt in Netscape format, exported from a browser with a "cookies.txt" extension. No password is ever stored.
Instagram session~/.fluorocap/instagram_session, created once by instaloader on any machine with a browser.
What I will never doPrint a value, write one to a log or a commit, or send one anywhere but the service it belongs to. check reports names and pass/fail only.

02Free API keys, about five minutes each

  1. Contact emailFLUOROCAP_CONTACT_EMAILAny lab or role address. Identifies the harvester on the Crossref, Unpaywall and NCBI polite pools. Put this in first; the refetch and every literature route use it.
  2. NCBI E-utilitiesNCBI_API_KEY · account.ncbi.nlm.nih.gov/settings → API Key Management → CreateTen requests a second instead of three. The refetch resolves 2,900 figures through NCBI; this triples its speed.
  3. YouTube Data API v3YOUTUBE_API_KEY · console.cloud.google.com → new project → Enable APIs → YouTube Data API v3 → Credentials → API keyProper search and channel enumeration, 10,000 units a day (about 100 searches). Video frames are the only source that is 1080 px native; the current route scrapes search pages and misses most of what the API returns.
  4. Springer NatureSPRINGER_API_KEY · dev.springernature.com → Sign up → API keyFigure lists for every Springer, BMC and Nature article without touching a landing page.
  5. ElsevierELSEVIER_API_KEY · dev.elsevier.com → register with the Wayne State affiliation → API keyArticle Retrieval API for World Neurosurgery, The Spine Journal, Clinical Neurology and Neurosurgery. The key is free; entitlement to closed articles comes from the institution, section 03.
  6. FlickrFLICKR_API_KEY · flickr.com/services/apps/createOriginal-size downloads on the archive route.
  7. RedditREDDIT_CLIENT_ID, REDDIT_CLIENT_SECRET · reddit.com/prefs/apps → create app → type "script"The Reddit route without rate-limit stalls.
  8. Google Programmable SearchGOOGLE_CSE_KEY, GOOGLE_CSE_CX · programmablesearchengine.google.com (search the entire web, image search on), key from the Cloud consoleImage search over surgeon and practice websites. 100 free queries a day.
  9. PatentsViewPATENTSVIEW_API_KEY · patentsview.org/apis/keyrequestThe patent-drawing route; Google Patents cut us off after forty requests.

03Wayne State institutional access

For Spine, Neurosurgery, JNS Spine, European Spine Journal and the other subscription titles whose author manuscripts sit in PMC at whatever size the author uploaded. Two routes, in order of preference.

  1. Try the campus IP first, it costs nothingThe grid is inside the university's address space (141.217.x.x) and publishers authenticate by IP. I will run the closed-journal refetch from the grid login node with a browser-impersonating client before asking you for anything. Today's probe was inconclusive only because Wolters Kluwer refuses plain clients outright.
  2. If that fails: export the proxy session cookieWSU_PROXY_PREFIX + ~/.fluorocap/cookies/wsu_proxy.txtLog in to the library proxy once in a browser (AccessID, password, Duo). Export the cookies for the proxy host with a "cookies.txt" extension and save the file to that path. Set the prefix to the library's link prefix; it is on every "Find it @ WSU" link. The cookie expires; check tells you when to export it again. Your password is never stored.

Two cautions

The library note of 30 June 2026 says DMC residents were dropped from WSU library access. Confirm your current affiliation still authenticates before exporting anything.

Every publisher licence forbids systematic downloading, and publishers block a whole institution's range when they detect it. The refetch touches only the closed-journal figures that already carry a matched caption (about 600), one request every three seconds per host, capped per day, never full text or PDFs in bulk. The clean way to do this at scale is the publishers' own text-and-data-mining APIs, which the institutional licence covers: Elsevier and Springer above, and Wiley's WILEY_TDM_TOKEN from onlinelibrary.wiley.com/library-info/resources/text-and-datamining. Asking the library for the TDM terms is a five-minute email and removes the risk entirely.

04Instagram and Facebook

Instagram serves posts at 1080 px wide, larger than the median journal panel, and the captions are written by the people who took the films. It serves almost nothing to an anonymous client, so the route runs on a logged-in session.

pip install instaloader
instaloader --login USERNAME            # or, from a browser already logged in:  instaloader --load-cookies firefox
cp ~/.config/instaloader/session-USERNAME ~/.fluorocap/instagram_session
# then in credentials.env:  INSTAGRAM_USERNAME=USERNAME

Read before choosing the account

Meta's terms prohibit automated collection. Accounts used for it get action-blocked, then disabled. Use a dedicated account, not the one attached to your name or practice. The harvester walks hashtags and named accounts at the slow end of what the library allows, one post every 8 to 20 seconds, and sleeps an hour on the first rate-limit response. It keeps the caption, the poster, the date and a licence line saying the image is the poster's and is held for research review only.

Facebook: no tool works reliably in 2026. A cookie jar exported from a logged-in browser can be given as FACEBOOK_COOKIES and the same script will try public groups. Expect it to break.

05Not worth buying

X/Twitter's API is $100 a month for seven-day search, which cannot reach the historical posts that hold the images. TikTok has no public API; yt-dlp fetches public TikTok videos by URL with no credentials, so that route needs URLs, not keys.

06The order to do it in

  1. Run init, put the contact email in, run check.The credential-free refetch is already running on nothing more than this.
  2. NCBI, YouTube, Springer, Elsevier keys.Twenty minutes total. Run check again; I take it from there.
  3. Let me try the closed journals from the grid IP.Only if that fails, export the proxy cookie.
  4. Instagram session from a dedicated account.
  5. Flickr, Reddit, Google search, PatentsView when convenient.
