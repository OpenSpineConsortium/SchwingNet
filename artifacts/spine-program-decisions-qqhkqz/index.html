Spine Program Decisions

Every call made this session, and what it buys you

Twelve decisions across the paper, the network architecture, the data and the governance — each with the evidence behind it and what it commits you to. Then the corpus as it now stands, and what can actually be built on it.

Decisions

the ones that were not obvious
One network, four heads — not separate models, not one flat class list locked

A VinDr film has lesion boxes and no corners; a CSXA film has corners and no lesion boxes. Concatenated into one class list, every CSXA image teaches the model “no osteophytes here” — which is false, nobody looked.

Shared backbone. Vertebra detection + 4 keypoints, a level head, a lesion head, and later Cobb landmarks. Each head’s loss is masked to zero on images not annotated for it. Prior art: Zhou’s UniDet (CVPR 2022) matches dataset-specific models on every training domain; Yan’s LENS (IEEE TMI 2021) is the medical version, +49% sensitivity.

Level identity goes on a head, never on the detector locked

C3 appears only in CSXA, T7 only in AASCE. A detector with level classes can hit near-perfect training accuracy by reading which dataset the image came from. A ResNet50 identifies source dataset from chest X-ray contours alone at 86.6% F1 — the signature survives intensity normalisation.

The level head reads pooled features inside the detected box, so it only ever sees the vertebra itself. This is your local-level-identity thesis, moved to 2D — and it is the reason the architecture question mattered at all.

Adding CSXA is what makes the level experiment possible locked

Not mainly for volume. Cervical levels were covered by one source, so a train-here/test-there experiment could not be run at all.

Cervical is now covered by CSXA and NHANES independently. Train the level head on one, test on the other: survives the swap, it is morphology; collapses, it was signature. No published work tests cross-dataset generalisation of level identity.

One training fold while debugging, not five in effect

Five folds on one node made each other slow: the first to land stages to local NVMe and the rest fall back to NFS. Fold 2 also died on a 16 GB V100 with a plan built for 100 GB — nothing to do with the model.

Fold 4 alone on an H200, resumed from its checkpoint at epoch 50. Vertebrae are at Dice 0.82–0.95. See the open question below about whether five folds can ever measure the rare classes.

Gate on geometry, never on the answer locked

The figure had been dropping records whose pelvic tilt was below −15° — removing them by their result, which hides the defect that produced it.

The real fault was a plate normal leaning posteriorly, which the tilt gate could not see because it measures only the angle from vertical. 39/39 of the bad records lean back, 0/39 of the good ones. Now rejected on orientation; the value filter is gone.

Withhold L5 rather than publish it with a caveat locked

End-plate and pedicle width both come from a body isolated by cutting at the canal wall, and the L5 transverse processes arise in front of that wall. Three replacement rules were built and run over all 802 records; none beat the one that ships.

L5 dropped from those two panels and from level_atlas.csv. A number wrong in an eighth of the cohort, in a figure whose point is telling whether a patient is unusual, is worse than one fewer row.

Research first on licensing, enforced in code in effect

Nothing in a checkpoint records what it saw, so a README is not a control.

src/licensing.py makes the exporter unable to select a forbidden source. Commercial-clean today: CSXA, the 208 Honduran images, NHANES if counsel agrees. VinDr is research-only by its PhysioNet licence — that is the entire lesion corpus.

No LICENSE means all-rights-reserved by default — a commercial concern, not a research one, and you made the call.

20,000 synthetic scoliosis films with 19,999 Cobb-angle triples and COCO annotations. Same label schema as AASCE at 35× the volume. Tagged research-track so the gate keeps it out of any commercial lineage automatically.

The experiment

Prove 3D morphology transfers to 2D

Train the level head on DRRs where the level is certain, test on real radiographs.

6,416 DRRs, one rendering style, no source confound

No published work uses DRRs to supply level identity to a 2D model — everyone uses them for landmarks, registration or 3D reconstruction. This is the opening.

The one open question that changes the plan

L6 has scored Dice 0.00 in every run, every fold, every epoch investigating

Ten training runs, one reaching epoch 83. Never once above zero — so it is not a regression and not “too early”. About 22 of 802 cases carry an L6 at all, roughly 2.7%.

With five folds that is four or five validation cases per fold, and nan is already appearing — meaning some epochs have none. nnU-Net’s foreground oversampling is per-patch and class-agnostic, so an L6 will almost never be the sampled class inside a 384×256×256 patch. The rare transitional classes are exactly the phenotypes the dataset exists to capture, and they are the ones the training setup cannot see.

Counting how the rare classes fall across the five folds is running now. It decides whether consolidating folds helps, or whether the fix has to be class-aware patch sampling.
